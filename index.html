Segurança da conta

Este painel usa o mesmo login e banco de dados do casal (Firebase Authentication + Firestore). Só os e-mails autorizados por vocês dois conseguem entrar, e os dados trafegam sempre criptografados (HTTPS). As regras do banco de dados (Firestore Rules) devem restringir a leitura e escrita apenas aos dois UIDs do casal — veja o guia de implantação enviado junto com este arquivo.

Novo lançamento

Lançar pelo WhatsApp

A forma mais rápida sem custo é instalar este painel como atalho no celular (toque em "Adicionar à tela inicial") e usar o botão "+ Novo lançamento" — leva menos de 10 segundos, o mesmo tempo de mandar uma mensagem.

Um bot de WhatsApp de verdade (você manda "50 mercado" e ele lança sozinho) é possível, mas exige um pequeno servidor sempre ligado recebendo mensagens da API do WhatsApp — isso tem um custo mínimo mensal ou o uso do plano pago do Firebase (Blaze), mesmo ficando dentro da faixa gratuita de uso. Quando vocês estiverem prontos para esse passo, é só pedir que eu monte esse bot.
